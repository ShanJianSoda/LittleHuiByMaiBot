以下为完整开发文档。目标是将 `get_global_vad()` 输出的连续 VAD 三维情绪数据，映射为可实时更新的“情绪熔岩灯”视觉系统。系统需具备平滑过渡、物理隐喻一致性、时间连续性与可扩展性。

——————————————————
一、系统目标
——————————————————

构建一个实时视觉系统：

输入：
VAD = (Valence, Arousal, Dominance) ∈ [-1, 1]

输出：
动态流体视觉表现，包括：

- 颜色
- 溶液数量
- 溶液体积
- 聚合/分裂行为
- 流动速度
- 容器晃动

视觉变化必须连续、无突变、符合情绪隐喻逻辑。

——————————————————
二、系统总体架构
——————————————————

系统分为六层：

1. 数据采集层
2. 情绪平滑层
3. 情绪惯性/能量池层
4. 参数映射层
5. 流体模拟层
6. 渲染层

——————————————————
三、数据采集层
——————————————————

接口：

```
def get_global_vad() -> tuple[float, float, float] | None
```

轮询策略：

读取频率建议：
60Hz（与渲染帧同步）
或 30Hz（最低）

实现：

- 启动一个定时任务
- 每帧读取一次
- None 时保持上一状态

示例伪代码：

```
def poll_vad():
    state = get_global_vad()
    if state is not None:
        target_vad = state
```

避免将读取频率与模拟频率绑定。读取频率可低于渲染频率。

——————————————————
四、情绪平滑层（Temporal Filtering）
——————————————————

问题：VAD 会跳变，视觉系统不能瞬间改变。

使用指数平滑：

```
smoothed_v = lerp(prev_v, target_v, alpha_v)
smoothed_a = lerp(prev_a, target_a, alpha_a)
smoothed_d = lerp(prev_d, target_d, alpha_d)
```

alpha 推荐：

Valence：0.02（慢）
Arousal：0.08（快）
Dominance：0.05（中）

或使用时间常数：

```
alpha = 1 - exp(-dt / tau)
```

推荐时间常数：

Valence τ=2.0s
Arousal τ=0.6s
Dominance τ=1.2s

——————————————————
五、情绪惯性 / 能量池模型
——————————————————

避免直接映射。建立“情绪能量池”。

定义：

```
emotion_energy += |target_vad - smoothed_vad|
emotion_energy *= decay_rate
```

建议：

decay_rate = 0.995 / frame

能量影响：

- 流体扰动强度
- 颜色脉冲幅度
- 容器晃动幅度

这一步制造“余波感”。

——————————————————
六、参数映射层
——————————————————

VAD ∈ [-1,1]
先归一化：

```
nv = (v + 1) / 2
na = (a + 1) / 2
nd = (d + 1) / 2
```

——————————

1. 颜色映射
   ——————————

HSV 空间：

Hue = lerp(220°, 20°, nv)
Saturation = 0.3 + 0.7 * na
Value = 0.4 + 0.6 * na

Dominance 影响：

- nd 高 → 主色纯净
- nd 低 → 增加 secondary hue 混色

Secondary hue：

```
h2 = h + random_noise * (1 - nd)
```

——————————

2. Blob 数量映射

——————————

```
blob_count = 3 + int(na * 10)
```

高 Arousal → 多碎片

——————————

3. Blob 尺寸

——————————

```
blob_size_mean = lerp(large, small, na)
```

——————————

4. 表面张力（聚合强度）

——————————

```
surface_tension = lerp(low, high, nd)
```

Dominance 高 → 容易聚合

——————————

5. 粘度

——————————

```
viscosity = lerp(high, low, nv)
```

负情绪更粘稠

——————————

6. 上浮力

——————————

```
buoyancy = lerp(downward, upward, nv)
```

正情绪 → 上浮
负情绪 → 下沉

——————————

7. 湍流强度

——————————

```
turbulence = base + na * k + emotion_energy * m
```

——————————————————
七、流体模拟实现方案
——————————————————

推荐方案：Metaball + Curl Noise（实时稳定）

原因：

- GPU 友好
- 可控
- 易绑定参数

——————————

1. Metaball 基础
   ——————————

每个 blob：

```
position
velocity
radius
color
```

场函数：

```
F(x) = Σ (r_i² / |x - p_i|²)
```

阈值：

```
if F(x) > threshold → inside
```

threshold 绑定 Dominance。

——————————

2. 运动模型

——————————

速度更新：

```
velocity += buoyancy_force
velocity += curl_noise(position) * turbulence
velocity *= damping
position += velocity * dt
```

——————————

3. 聚合

——————————

当两个 blob 距离 < merge_threshold 时：

```
merge if nd > random()
```

——————————

4. 分裂

——————————

当 na 高：

```
if radius > threshold and random() < na:
    split blob
```

——————————————————
八、容器晃动系统
——————————————————

实现“呼吸感”。

重力扰动：

```
gravity.x = sin(t * freq) * amplitude
```

freq = 0.1 + na * 1.5
amplitude = 0.02 + emotion_energy * 0.05

低频 oscillation。

——————————————————
九、渲染层
——————————————————

建议 Shader 包含：

1. Subsurface scattering 近似
2. Fresnel 边缘高光
3. 内部渐变
4. 多层噪声

颜色混合方式：

HSV 线性插值
避免 RGB 插值产生灰色污染。

——————————————————
十、状态机与边界处理
——————————————————

1. get_global_vad() 返回 None
   → 保持当前状态
   → slowly decay emotion_energy
2. 极端跳变
   → 限制每帧最大变化率

```
delta = clamp(target - prev, max_step)
```

——————————————————
十五、核心原则总结
——————————————————

1. 不直接映射，必须时间平滑
2. 情绪变化应有余波
3. 不让单一维度支配全部视觉
4. 视觉变化必须连续
5. 物理参数必须有隐喻逻辑

这是一个跨域映射系统：
心理空间 → 参数空间 → 动力系统 → 光学表现。

系统稳定性取决于时间连续性，而非映射函数本身。
