# 情绪模块开发文档

**目标**：为 MaiBot 构建一个“拟连续、可学习、可解释”的情绪引擎（基于 Russell 的 Valence–Arousal / Circumplex 模型），能按秒级/消息驱动更新情绪状态，并把情绪用于（1）生成语气/风格控制、（2）行为/决策逻辑（含记忆检索优先级）、（3）社交情绪传染与共情。此文档提供数学模型、候选实现路线、训练与评估方案、工程接口与部署细节、参考实现与数据源。

> 核心引理（重要引用）
> *情绪以二维连续向量表示（Valence, Arousal），这是心理学标准表述。* ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC2367156/?utm_source=chatgpt.com))
> 文本→V/A 映射与词汇表（NRC VAD）与大规模情绪数据集（GoEmotions）是训练与评估的重要资源。 ([Saif Mohammad](https://saifmohammad.com/WebPages/nrc-vad.html?utm_source=chatgpt.com))
> 多模态融合（视频/音频/文本）常用粒子滤波/贝叶斯滤波技术以稳健估计实时情绪。 ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC4187218/?utm_source=chatgpt.com))
> 迁移学习（DeepMoji / 语料）在文本情绪识别上被广泛使用以提升泛化能力。 ([GitHub](https://github.com/bfelbo/DeepMoji?utm_source=chatgpt.com))

# 1. 概览与设计原则

- **表示**：使用二维连续向量 `s_t = (v_t, a_t)`，v ∈ [−1,1], a ∈ [−1,1] 或 a ∈ [0,1] （建议统一到 [−1,1]）。（Russell circumplex） ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC2367156/?utm_source=chatgpt.com))
- **更新频率**：事件驱动（每条消息）并支持周期性衰减（每 2–10s 做一次“内部”步进，可配置），实现“伪连续”感。
- **模块职责划分**：
  - 感知层：把消息→即时情绪线索（文本情感估计）
  - 预测器：消息线索 → Δs (增量)（可用 NN / regression / lexicon）
  - 动力学层：将 Δs 应用到 s_t（衰减、惯性、约束）
  - 滤波/融合：时间平滑或多模态融合（Kalman / particle）
  - 行为层：情绪→生成提示、行为策略调整、记忆加权
  - 学习层：长期自适应（监督/自监督/强化）

设计目标是**可解释 + 可训练 + 稳定**：首要保证运行时一致性（不会被单条消息大幅抖动），其次支持训练以提高语义映射精度。

# 2. 情绪表示与状态演化（数学详式）

## 2.1 基本状态

定义情绪状态向量
[
\mathbf{s}_t = \begin{bmatrix} v_t \ a_t \end{bmatrix},\quad v_t,a_t\in[-1,1]
]

## 2.2 离散更新（指数衰减 + 增量）

事件驱动或定时步长 Δt：
[
\mathbf{s}_{t+1} = \mathrm{clamp}\big( \mathbf{s}*t \odot e^{-\Delta t/\boldsymbol{\tau}} + \boldsymbol{\kappa}\odot \Delta\mathbf{s}*{\text{input}},, -1,1\big)
]

- $\boldsymbol{\tau}=[\tau_v,\tau_a]$: 衰减时常（秒）。
- $\boldsymbol{\kappa}=[\kappa_v,\kappa_a]$: 刻度/敏感度。
- $\Delta\mathbf{s}_{\text{input}} = (\Delta v, \Delta a)$：来自“感知→预测器”的增量估计。
- clamp：逐元素裁剪到范围。
  此式等价于一阶欧拉积分的解（连续时间 $ \dot{\mathbf{s}} = -\mathbf{s}/\tau + \kappa \cdot u(t)$）。

## 2.3 惯性 / 二阶项（防抖）

可加入速度项 $ \mathbf{u}*t $：
[
\begin{aligned}
\mathbf{u}*{t+1} &= \beta \mathbf{u}*t + (1-\beta)\Delta\mathbf{s}*{\text{input}}\
\mathbf{s}_{t+1} &= \mathrm{clamp}(\mathbf{s}*t \odot e^{-\Delta t/\tau} + \alpha\mathbf{u}*{t+1}, -1,1)
\end{aligned}
]

- $\beta$ 形同动量系数（0.6–0.95）。

## 2.4 基于高斯原型的刺激响应（RBF）

将事件 $i$ 投影到情绪原型 $(v_i,a_i)$，影响幅度：
[
w_i = A_i\exp\left(-\frac{|\mathbf{s}_t - \mathbf{p}*i|^2}{2\sigma_i^2}\right)
]
并构造 $\Delta\mathbf{s}*{\text{input}}=\sum_i w_i\cdot \mathbf{d}_i$，$\mathbf{d}_i$ 为事件方向向量（可是原型到目标的向量或直接标注值）。

## 2.5 概率/贝叶斯观点（不确定性）

如果用概率分布表示状态 $p(\mathbf{s}_t)$，可用扩展卡尔曼滤波（EKF）或粒子滤波处理非线性与多模态观测：

- 观测模型 $y_t \sim p(y|\mathbf{s}_t)$（例如文本情感器给出 noisy measurement of $(v,a)$）。
- 递推: predict（动力学）→ update（观测融合）。
  粒子滤波在多模态或观测噪声大时更稳健（适合多模态：文本+语音+视频）。 ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC4187218/?utm_source=chatgpt.com))

# 3. 输入编码（文本为主；预留音频/图像）

## 3.1 文本→情绪信号方法（可组合）

- **词典映射（快速、低成本）**
  - 使用 NRC-VAD、ANEW 等词表对句子词汇加权平均得 V/A 基线值。 ([Saif Mohammad](https://saifmohammad.com/WebPages/nrc-vad.html?utm_source=chatgpt.com))
  - 优点：解释性强、实时、不需训练。缺点：对上下文/否定/讽刺敏感性差。
- **监督模型（Transformer/RoBERTa）回归 V/A**
  - 输入：句子或上下文；输出：连续值 (v', a')。可用 GoEmotions、EmoBank 等数据微调或用现成情感模型作为初始化。 ([ACL Anthology](https://aclanthology.org/2020.acl-main.372/?utm_source=chatgpt.com))
  - 优点：性能高、上下文感知；缺点：需标注数据/算力。
- **迁移学习（DeepMoji / BERT）**
  - 用预训练情绪相关模型提取特征，再用小回归头输出 V/A。 DeepMoji 提供强迁移能力。 ([GitHub](https://github.com/bfelbo/DeepMoji?utm_source=chatgpt.com))

## 3.2 多消息上下文编码

- 将若干历史消息编码（Transformer encoder / sliding window），并输出当前观测 $y_t$。
- 观测应带置信度 $c_t$（模型对 v,a 的置信），用于滤波器加权更新。

## 3.3 预留音频/视觉（接口）

设计 `perception` 接口接收 `{ modality: 'text'|'audio'|'video', payload, timestamp }`，每种 modality 返回 measurement `{v,a,confidence}`。多模态融合交给滤波器（粒子/卡尔曼）。

# 4. 实现路线（四种 + 推荐混合方案）

> 每种方法都给出：原理、优缺点、资源需求、是否适合 MaiBot。

## 4.1 方案 A — 纯规则 + 动力学（轻量、可解释）

- **流程**：文本→词典/规则→快速计算 Δs → 动力学更新（指数衰减/动量）。
- **优点**：极低运行成本、可解释、零训练数据需求、易调参。
- **缺点**：难以处理复杂语义/讽刺、情绪识别精度受限、难以长期学习。
- **适合场景**：资源有限，需最低阻力集成（快速原型）。
- **建议与 MaiBot**：把词典映射作为 baseline；生产环境用作 fallback。

## 4.2 方案 B — 神经网络回归器（Transformer/RNN）→ Δs

- **流程**：文本上下文输入 Transformer encoder → MLP 回归输出 $(\Delta v, \Delta a, conf)$ → 动力学更新 → 行为层。
- **优点**：高语义理解能力、能从数据学习复杂模式、支持长期微调。
- **缺点**：训练数据需求高（但可用迁移学习），实时推理开销较大（可用 distill 或小型 transformer）。
- **适合场景**：需要高精度、能承受 CPU/GPU，长期学习。
- **资源**：GoEmotions、NRC-VAD、EmoBank 用于微调。 ([ACL Anthology](https://aclanthology.org/2020.acl-main.372/?utm_source=chatgpt.com))

## 4.3 方案 C — 贝叶斯/滤波器（卡尔曼/粒子）作时间融合（感知融合核心）

- **流程**：每条消息或模态产出观测 $(v,a,c)$ → 粒子/卡尔曼融合 → 后验 $p(\mathbf{s}_t)$ → 取期望或样本作为状态。
- **优点**：处理观测噪声、多模态融合稳定、可给出不确定度；适合连续估计。 ([PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC4187218/?utm_source=chatgpt.com))
- **缺点**：需要设计观测模型；粒子滤波计算量随粒子数上升。
- **适合场景**：多模态情绪推断、需要不确定度估计的场景。

## 4.4 方案 D — 强化学习 / 元控制层（情绪→行为学习）

- **流程**：情绪作为状态的一部分进入 RL agent，代理学习如何基于情绪与上下文决定回复策略（优化长期用户满意度/engagement）。
- **优点**：可学习长期目标（如用户留存、自然感）；情绪驱动行为会自我校正。
- **缺点**：训练成本高、需要奖励信号（可用隐性信号：会话长度、正反馈、回复速度）。
- **适合场景**：产品级机器人，追求长期交互质量。

## 4.5 **推荐混合路线（工程与性能平衡）** ← **首选实现方案**

**组合：** Transformer-based perceptual regressor (文本→(v',a',conf)) + Dynamics (decay + momentum) + Bayesian/Particle smoothing + RL policy for behavior tuning。
**理由**：兼顾感知精度（神经网）与时序稳定（滤波/动力学）、还能长期学习（RL/online fine-tune）。适合 MaiBot 的插件化架构和在线部署要求。

# 5. 学习 / 训练策略与数据集（细化）

## 5.1 数据资源（建议）

- **NRC VAD** (valence, arousal, dominance lexicon) — 词表，用于 lexicon baseline & weak supervision。 ([Saif Mohammad](https://saifmohammad.com/WebPages/nrc-vad.html?utm_source=chatgpt.com))
- **GoEmotions (Google)** — 大规模情绪分类（58k Reddit 注释），可用于多标签预训练/迁移。 ([ACL Anthology](https://aclanthology.org/2020.acl-main.372/?utm_source=chatgpt.com))
- **EmoBank / EmoNet / Aff-Wild / MAVEN** — 含 V/A 标注或多模态情绪数据，用于回归训练或多模态模型。 （MAVEN repo示例可参考） ([GitHub](https://github.com/Vrushank-Ahire/MAVEN_8th_ABAW?utm_source=chatgpt.com))
- **DeepMoji** 大规模 emoji 作监督，适合迁移学习。 ([GitHub](https://github.com/bfelbo/DeepMoji?utm_source=chatgpt.com))

## 5.2 训练目标与损失

- **回归损失**（文本→V/A）：L1 / L2；优先使用 **CCC (Concordance Correlation Coefficient)** 与 Pearson 作为评价指标（情感维度任务常用）。
- **置信度输出**：回归 + 不确定性估计（MC-Dropout、ensemble 或直接输出方差，用负对数似然训练）。
- **RL 层**：策略网络以对话质量（用户反馈、任务成功率、会话留存）作为回报信号。训练分阶段：先离线训练行为策略，再在线微调（安全约束）。

## 5.3 半监督 / 自监督与在线学习

- 使用模型预测 + 人类反馈（ratings）做 RLHF 式微调。
- 自监督：把高唤醒 / 强情绪事件作为“重要”，以对比学习增强表示稳定性。
- 在线自适应：使用滑动窗口历史数据更新轻量梯度（低学习率），并对关键超参（$\tau,\kappa$）做梯度/贝叶斯优化。

# 6. 集成到 MaiBot（工程规范与 API 设计）

## 6.1 模块边界（建议）

- 新建服务 `emotion_engine`（独立进程或库模块）：负责感知、预测、动力学、融合、存储、提供查询 API。
- Hookpoints in MaiBot pipeline：在消息接收后、在生成前查询/更新情绪。
  - **消息接收阶段**：`on_message(msg)` → `emotion_engine.observe(msg)` → engine returns updated s_t。
  - **生成阶段**：`response = LLM.generate(prompt + emotion_context(s_t))`。
  - **行为阶段**：`decision = policy(observation, s_t)`（用于是否检索记忆、改变语气、改变应答长度等）。

## 6.2 API（示例）

- `POST /emotion/observe`
  payload: `{chat_id, message_id, text, author_id, timestamp}`
  returns: `{v,a,confidence,tags}`
- `GET /emotion/state?chat_id=...`
  returns: `{v,a,last_updated,history_url}`
- `POST /emotion/override`（管理员/测试）
  payload: `{chat_id, v,a,reason,ttl}`

## 6.3 存储 schema（SQLite / Postgres）

表 `emotion_states`：

```
chat_id TEXT
ts TIMESTAMP
v REAL
a REAL
source TEXT
conf REAL
delta_v REAL
delta_a REAL
```

表 `emotion_history` — 时间序列保留策略（压缩存储、只保存关键点或窗口）。

## 6.4 运算预算与频率

- **Per-message**：文本感知（Transformer) → 输出 (v',a')，若消息频率高，先聚合短时间窗口（例如 2–5s）再调用感知器。
- **周期 Task**：每 `tick`（2–10s）执行动力学衰减与平滑步骤。
- 对于 MaiBot 单实例，推荐使用 GPU 进行感知模型推理（若无则部署 distilled model）。

## 6.5 Prompting for LLM style influence

将 s_t 映射为短文本提示片段插入 LLM prompt：

```
# emotion-context snippet
Emotion: valence=0.6 (slightly positive), arousal= -0.2 (calm)
Style: warmer, slightly enthusiastic, concise.
```

或者映射为 discrete labels via thresholds（v>0.5 -> "happy"）并供 LLM 条件化。

# 7. 监控、评估与实验计划

## 7.1 离线评估（模型性能）

- 回归指标：CCC、Pearson r、RMSE。使用 EmoBank/GoEmotions/VAD-annotated corpora做验证集。 ([ACL Anthology](https://aclanthology.org/2020.acl-main.372/?utm_source=chatgpt.com))
- 置信度校准：Expected Calibration Error (ECE)。
- Ablation：移除动力学 vs 加入滤波的对比。

## 7.2 在线 A/B 测试（行为层）

- 指标：会话长度、用户正向反馈率、回复延迟、对话满意度评分。
- 实验：比较“情绪驱动策略” vs “非情绪基线”。

## 7.3 监控运行时

- 时序可视化 dashboard：plot v_t,a_t 曲线、最近触发原因、置信度。
- 自动告警：若 |v|/|a| 超阈值或滤波发散，发送告警并切换到 safe-mode（将情绪输出设为中性）。

# 8. 参数建议（初始值与调参）

- 状态范围：v ∈ [−1,1]， a ∈ [−1,1]（统一双向）
- 衰减时间常 $\tau_v,\tau_a$：初始 120s（2 分钟）作为“短暂情绪”，可调 60–600s 视场景。
- 敏感度 $\kappa_v,\kappa_a$：0.3–1.0（强事件接近 1），训练阶段可通过 gridsearch 微调。
- 动量 β：0.8–0.95（平滑程度）。
- 最小更新间隔：2s；消息聚合窗口：2–5s（高频场景）。
- 粒子滤波：粒子数 200–1000（多模态/高噪场景增大），卡尔曼则用于线性近似场景。

# 9. 安全、伦理、合规

- **情绪操纵风险**：情绪建模会让机器人有“影响人情绪”的能力，避免滥用。设计上加入显式限制（如不得诱导恐惧、不得针对弱势群体）。Facebook 情绪实验的争议提示需谨慎。 ([WIRED](https://www.wired.com/2014/06/everything-you-need-to-know-about-facebooks-manipulative-experiment?utm_source=chatgpt.com))
- **用户告知**：若系统显式使用用户情绪数据，需符合隐私政策。
- **回滚与安全开关**：在情绪驱动策略导致异常行为时，应有强制“中性”回退。

# 实施步骤（工程化路线、最少阻力到成熟版本）

## 进阶实现（2–6 周）

1. **滤波器融合**：加入简单卡尔曼或粒子滤波平滑，输出置信区间。
2. **行为映射层**：实现 emotion→prompt 模块（将 s_t 转为 LLM prompt snippet）并在 MaiBot 中集成。
3. **存储与历史**：实现 DB schema +仪表盘 +监控告警。

## 成熟系统（3–6 月）

1. **长期学习**：在线微调感知器 + RL 政策训练（离线回放，线上微调）以优化交互指标。
2. **多模态扩展**：若引入声音/视觉，加入粒子滤波与多模态网络（MAVEN-like）。 ([GitHub](https://github.com/Vrushank-Ahire/MAVEN_8th_ABAW?utm_source=chatgpt.com))

# 示例关键代码片段（伪代码，Python 风格）

### 动力学更新（核心）

```python
def update_state(s, u, dt, tau, kappa, beta, momentum):
    # s: [v,a], u: observed delta [dv,da], momentum: prev momentum
    momentum = beta*momentum + (1-beta)*u
    decay = np.exp(-dt/np.array(tau))
    s_new = np.clip(s * decay + kappa * momentum, -1.0, 1.0)
    return s_new, momentum
```

### 简单感知器（Transformer→回归）

```python
# using HuggingFace
class VARegressor(nn.Module):
    def __init__(self, base_model):
        super().__init__()
        self.encoder = base_model
        self.head = nn.Sequential(nn.Linear(enc_dim, 128), nn.ReLU(), nn.Linear(128,2))
    def forward(self, input_ids, attention_mask):
        x = self.encoder(input_ids, attention_mask)[0][:,0,:]
        out = torch.tanh(self.head(x))  # output in [-1,1]
        return out
```

### 粒子滤波骨架（概念）

- 初始化 N 粒子，粒子表示 s. 每步：predict（apply decay & process noise）→ compute weight from observation likelihood p(y|s) → resample → estimate mean.
